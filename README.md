# RomRaider2 Releases

Official public downloads for RomRaider2 ECU Studio.

The active development repository is private. This public repository is intentionally limited to release downloads, checksums, release notes, and the corresponding source archive required for each GPL-distributed build.

Use the Releases section to download builds for supported platforms. Release packages are prerelease/testing builds unless explicitly marked stable.

For each release:
- compiled platform packages have SHA-256 sidecars;
- the exact corresponding source is attached as a Corresponding_Source.zip asset with its own SHA-256 sidecar;
- the browsable/tagged repository tree contains only this README.

The corresponding-source archive is the release source for GPL purposes. It does not expose the newer private development branch or ongoing unreleased work.
